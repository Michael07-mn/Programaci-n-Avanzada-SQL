# Programaci-n-Avanzada-SQL

**Objetivo de la actividad:** 


Ampliar el sistema de gestión de matrículas mediante la creación de vistas, 
funciones, procedimientos almacenados y triggers, aplicando buenas prácticas 
de programación en SQL para mejorar la seguridad, la eficiencia y la 
automatización en la gestión de bases de datos.
